Publicar uma versão nova

Escolhe o ficheiro normal «odoo-preparation-…user.js» (o legível, não o «protegido»). A página cifra-o, assina-o com a tua chave e envia-o para o GitHub. Os ecrãs dos clientes apanham-no sozinhos (de madrugada, com o ecrã parado) ou com 2 toques no separador «🔑 Licença».

Edição interna (a tua, protegida por código)

Escolhe o ficheiro protegido («…-protegido.user.js» feito com o código de segurança). Fica em internal/ e o Tampermonkey dos teus ecrãs atualiza-se sozinho a partir daí. É o mesmo ficheiro cifrado que já usas: só abre com o teu código.

Ligações para instalar

Quem tem o Tampermonkey instalado abre a ligação e carrega em «Instalar». A licença cola-se depois no separador «🔑 Licença» (ou usa o «ficheiro do programa deste cliente» na lista de clientes, que já traz a licença).

PCs ligados ao vivo

Só com o servidor de registo (Cloudflare, gratuito) o VueLux consegue dizer-te que PCs estão ligados agora e aceitar sozinho PCs novos até ao limite. Sem ele, os limites funcionam na mesma, mas és tu que autorizas cada PC (campo «Autorizar um PC» no cliente) e não há «ligado agora». Instruções no guia (parte «Cloudflare»).

Definições das licenças

«Sem ver o estado há N dias» (0 = nunca): se um ecrã ficar N dias sem conseguir ler o estado online, o VueLux desliga-se. Deixa em 0 se não precisas — uma falha do GitHub ou da internet do cliente não deve parar o serviço.

Avisar/Tolerância ficam dentro do ficheiro do programa; para mudar nos clientes é preciso publicar o instalador de novo (Versões → Publicar).

Endereços

Estes endereços ficam dentro do instalador. O endereço do servidor de registo só tem efeito depois de publicares uma versão estável.

Segurança e cópias

⚠ A cópia «JSON» tem a chave privada em claro: guarda-a como uma palavra-passe (pen, cofre). Se perderes a chave não consegues assinar versões compatíveis com os ecrãs já instalados.
